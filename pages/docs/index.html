Get started in minutes

Go from idea to running application.

1

Generate an application

Use the AI Engine to generate a Next.js UI and Prisma schema.

import { OneAtlas } from 'oneatlas';

await OneAtlas.generate({
  type: "Admin Panel",
  database: "neon-postgres"
});
